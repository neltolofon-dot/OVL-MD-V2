# Fruita Pineapple — 15 s motion spot (Remotion)

1920 × 1080 · 30 fps · 450 frames · H.264 + AAC · `out/fruita.mp4`
End frame / key visual: `out/keyvisual.png`

## Concept

The script comes from the can itself. The pack says
**SHAKE WELL BEFORE OPENING!**, so the film opens on _SHAKE WELL_, and the
end frame completes the sentence: _… BEFORE OPENING!_ All on-screen copy comes
from the packaging (PURE JUICE · 100% PINEAPPLE · NO ADDED CHEMICALS), and
every colour comes from the label: logo green, lime → sun → amber gradient,
cream highlight.

Colour script: deep green (hook) → sunlit studio built from the label
gradient (reveal) → alternating green / yellow / cream blocks (showcase) →
deep green with golden light (hero).

| Time | Act | What happens | Technique |
|---|---|---|---|
| 0 – 3 s | **Hook** | "SHAKE / WELL" slams in and trembles. The can whips up through the type and gets shaken so hard it flings its condensation, freezes on the downbeat, catches a light sweep, then the camera dives into the label. | kinetic type on the variable `wdth` axis, real multi-sample motion blur, particle physics, zoom-through |
| 3 – 7 s | **Reveal** | The camera pulls out of the same patch of label and lands on the can in a studio built from the label's own gradient. A continuous macro move then travels across the logo, the script and the illustration. | match cut on identical framing, 2.5D depth camera (parallax + depth of field), floor reflection, light sweep |
| 7 – 11 s | **Showcase** | **100%**: odometer counter whose zeros turn into spinning pineapple slices, and the camera dives through one of them. **PINEAPPLE**: the can tears across on a speed ramp and the letters ripple in its wake. **NO ADDED CHEMICALS**: diagonal shape wipe, letters stretch from condensed to expanded. **Real photos**: 8th-note montage of the real product in a card that morphs into the can. | odometer + motion blur, shape match cut, speed ramp, type reacting to the product, clip-path masking, card → can match cut |
| 11 – 15 s | **Hero** | Light and fruit blow outward on the drop, the camera eases back to the key-visual framing, "PINEAPPLE" draws itself behind the can, and the tagline lands word by word on the beat. "OPENING!" lands on the final chord and a can-opening *pssht*. | stroke-drawn SVG type, depth-sorted fruit, glints, final light sweep |

The match cut at the end of the montage is exact: the hero cut-out *is* the
centre can of the last photo. The card shrinks onto that can and then hands
over to the cut-out, with no hidden cut.

## Sound

`public/audio/fruita.wav` is generated by `scripts/make_soundtrack.py`
(numpy/scipy, no samples). It runs at 120 BPM in A major. A two-beat pickup
puts every act change (frames 90 / 210 / 330) on a downbeat.

Every sound effect sits on the frame of its visual event:
- shaker in 16ths during the shake
- the freeze hit
- risers into each drop, with a 50 ms duck just before it hits
- one odometer tick per digit, following the same easing curve as the counter
- shutter clicks on the montage cuts
- glints on the light sweeps
- a final can-opening *pssht* on "OPENING!"

The track is normalised to −14 LUFS.

## Build

```bash
npm install
npm run studio        # interactive preview
npm run render        # → out/fruita.mp4
npm run still         # → out/keyvisual.png (frame 449)

# optional — regenerate assets
pip install numpy scipy pillow opencv-python-headless "rembg[cpu]"
python3 scripts/prepare_assets.py     # cut-outs from assets/source → public/img
python3 scripts/make_soundtrack.py    # → public/audio/fruita.wav
```

On a machine without Remotion's own Chrome, pass
`--browser-executable=/path/to/chrome-headless-shell`.

## Layout

```
src/
  FruitaSpot.tsx      master timeline, whip pan between reveal and showcase, audio
  theme.ts            palette, timing grid, font (Archivo variable, OFL)
  lib/anim.ts         keyframe tracks, custom béziers, analytic springs, speed ramp
  lib/camera.ts       2.5D depth camera (parallax by layer depth)
  components/         Can (light sweep, shadow, reflection, glow), MotionBlur,
                      Bokeh, LightRays, Grain, Ring, PineSlice, Wedge, Drop
  scenes/             Hook, Reveal, Showcase, Hero
scripts/              asset preparation, soundtrack synthesis
assets/source/        the four supplied photos (untouched)
assets/mattes/        BiRefNet mattes (cached so the asset script is fast)
```

Every animation is a pure function of the (fractional) frame. That is what
lets the motion-blur sampler render true sub-frame positions.

## Notes

- The hero can comes from `fruita-keyvisual.webp`. That image carries an AI
  generator watermark in its bottom-right corner, which is cropped away and
  never appears on screen. If the brand needs real photography only, swap
  `IMG.can` for `IMG.canReal` (the desk photo). Its source is 584 px tall, so
  the macro shots in the reveal would get noticeably softer.
- The product is never recoloured or warped. Everything is added on top of the
  can (light sweep, glow) or around it (shadow, reflection).
- Remotion is free for individuals and companies of up to 3 people. Larger
  companies need a [company license](https://remotion.pro).
